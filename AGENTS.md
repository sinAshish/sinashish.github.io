Jekyll (al-folio) site. Push to `master` deploys.

## Map
- `_config.yml` site config; `_pages/` pages (`about.md` = home)
- `_posts/` blog; `_news/` news; `_projects/` projects
- `_bibliography/papers.bib` publications; `_data/` YAML (reading, photography, socials, coauthors)
- `_layouts/`, `_includes/` templates; `_sass/` styles; `assets/` static (`assets/pdf/` CV)
- Hide a post: `published: false` in front matter
- Local: `bundle exec jekyll serve`

## Preferences
- Terse; act, don't narrate.
- Errors: just fix.
- Do exactly what's asked; don't break existing behavior.
- Prioritize visual polish.
- Design changes: mockups first (lavish skill).
